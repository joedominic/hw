Set up your first search profile

My jobs organizes roles by search profile. Create one on Find jobs so saved and shortlisted jobs land in the right place.

  1. 1 Go to Find jobs and search for roles you want.
  2. 2 In the sidebar, click Save search and give it a name (e.g. FinCrimes, Remote Python).
  3. 3 Return here—your profile will be ready and jobs you save will show up by stage.
